# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 2.x (latest published release) | Yes |
| 1.x and earlier | No |

Pre-release versions published under the `next` tag are not covered by security support.

## Reporting a vulnerability

Please report vulnerabilities **privately** through GitHub:
open the repository's **Security** tab and choose **Report a vulnerability**
(private vulnerability reporting).

Do **not** open a public issue, pull request, or discussion for a suspected vulnerability,
and do not disclose it publicly until a fix has been released and the report has been coordinated with the maintainer.

Please include the affected version, a description of the impact, and steps to reproduce.
Never include real API keys or other credentials in a report.

## Scope

This policy covers only the code in this repository (the `geo-engine-node` SDK).
Issues in the GeoEngine service, its infrastructure, or third-party dependencies
should be reported to their respective owners.
